## Key Features to Demonstrate

### 1. User Authentication & Authorization
- Login as different user roles (Admin, Manager, Cashier)
- Show different menu options and permissions for each role
- Demonstrate user management (Admin only)

### 2. Inventory Management
- View product list with current stock levels
- Filter products by category, supplier, stock status
- Show low stock alerts
- Demonstrate product creation and editing
- Show product history and movement logs

### 3. Multi-Store Operations
- Switch between Main Store and Branch Store views
- Show stock levels in different stores
- Demonstrate stock transfer between stores
- View store-specific reports and analytics

### 4. Sales Operations
- Create a new sale
- Add multiple products to cart
- Apply discounts
- Process payment
- Generate and print invoice
- View sale history

### 5. Purchase Management
- Create purchase order
- Receive products
- Update stock levels
- View purchase history

### 6. Supplier & Client Management
- Add/Edit suppliers
- View supplier history
- Manage client information
- View client purchase history

### 7. Reports & Analytics
- Generate sales reports
- View profit margins
- Export data to Excel
- Show stock movement analytics

### 8. System Features
- Activity logging
- Stock alerts
- Database backup
- User notifications
